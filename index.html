정치 뉴스 스펙트럼 분석기는 아시아투데이 정치부 인턴 경험을 바탕으로 제작한 프로젝트입니다.

정치부 인턴 당시 여야 의원들의 발언과 보도자료를 매일 접하면서, 같은 사안에 대해 진보·보수 진영이 얼마나 다른 언어와 프레임으로 이야기하는지 실감했습니다. 이 시각 차이를 시각적으로 보여주면 뉴스 이용자들이 미디어를 더 비판적으로 읽는 데 도움이 될 것이라는 생각에서 이 프로젝트를 시작했습니다.

기술 스택: HTML / CSS / JavaScript · Claude API (Anthropic)
데이터: 아시아투데이 정치부 인턴 취재 기사 및 주요 현안 사설
